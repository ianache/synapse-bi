# Tipografías US-004

Hanken Grotesk y Plus Jakarta Sans, exportaciones WOFF2 variables sin modificación
del binario, subconjuntos Latin/Latin Extended. Se sirven localmente para que la
validación visual no dependa de Google Fonts. Alias CSS `US004 …` y variables
redefinidas sólo en `.synapse-models`: no sustituyen fuentes de otros workspaces.

Fuente de exportación: Google Fonts CSS2, Hanken Grotesk v12 (400–800) y Plus
Jakarta Sans v12 (400–700), consultado 2026-10-17. URLs de los binarios:
