# Indicador clave de desempeño (KPI)

- **ID:** TRM-0014
- **Tipo:** sigla
- **Forma completa:** Key Performance Indicator [N1 ISO 14031, https://www.iso.org/obp/ui?_escaped_fragment_=iso:std:iso:14031:ed-3:v1:es]
- **Sinónimos:** KPI [/intents/PRD.md:L21-L21]
- **Definición:** Métrica gobernada que expresa el desempeño del negocio y puede compartirse entre dashboards, API y experiencias de IA autorizadas. Para publicarse, declara definición, fórmula, unidad, grano, filtros, owner, versión, vigencia, fuentes, acceso, frescura y calidad.
- **Definición de referencia:** ISO 14031 define el indicador clave de desempeño como un indicador que la organización considera significativo y al que da protagonismo y atención para aspectos de sus operaciones, gestión, condiciones o impactos.
